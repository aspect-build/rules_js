# Yarn PnP zero-install e2e (Yarn 3.x)

Same layout as `e2e/pnp_zero_install`, but with artifacts generated by Yarn
3.8.7 (lockfile metadata version 6, bare sha512 checksums without a
cache-key prefix) to cover the Yarn 3.x flavor of the format on the import
and verification side.

Like the Yarn 4 fixture, all resolver, graph, config, lock, and cache inputs
are bound by `.pnp.integrity.json`. The lock's bare sha512 values remain an
independent checksum source for the cache archives.

Runtime execution is covered by the Yarn 4 fixture only; see the note in
BUILD.bazel for why the Yarn 3 `.pnp.cjs` runtime is not run under Bazel.
